# 使用手册 USER GUIDE — 灵感仓 INSIGHT VAULT

> 面向使用者。部署与环境变量见 [DEPLOYMENT](DEPLOYMENT.md)。

---

## 1. 第一次打开

1. 访问你的实例地址（默认 `http://localhost:3000`；桌面版打开应用即可）；
2. 点「注册」：填昵称、**邮箱**、**密码**（至少 8 位）→ 点「发送验证码」→ 把收到的 6 位数字填进去；
   **注册完成就是登录状态**，直接进收藏库；
3. 第一个注册的账号自动成为管理员。

### 之后每次登录

- 只要 **邮箱 + 密码**；上次用过的邮箱会自动填好，你只需要补密码；
- 默认勾选「在这台设备上保持登录（30 天）」，重开浏览器 / 重开桌面版都不用再登；
  公用电脑请取消勾选；
- 想不起来密码：登录页「忘记密码」→ 邮件里的重置链接（1 小时有效）；
- 也可以免密码登录：登录页底部「已有账号但想免密码登录？」→ 发 6 位码 → 填码登录。

### 验证码收不到？

- 先看垃圾箱；码的有效期是 5 分钟（登录）/ 15 分钟（注册）；
- 实例**没配 SMTP** 时，本机访问会进入「本地模式」：验证码直接显示在页面上并自动填入；
- 桌面版可以在托盘菜单 →「邮箱服务设置（SMTP）」里填一次，之后验证码就会真的发到邮箱。

界面默认中文。右上角头像里可以切换语言、主题（浅色/深色）。

## 2. 收藏

### 2.1 四种收藏方式

| 方式 | 操作 | 适合 |
|---|---|---|
| 粘贴链接 | 在首页「新项目」框里粘贴 URL，按 `⌘/Ctrl + Enter` | 网页、文章 |
| 拖入图片 | 把图片拖进同一个框 | 截图、灵感图 |
| 写笔记 | 直接输入文字 | 想法、摘录 |
| 浏览器扩展 | 扩展里点「保存到灵感仓」 | 整页剪藏、选中文字 |

快捷键：`⌘/Ctrl + E` 聚焦收藏输入框。

### 2.2 收藏之后会发生什么

```
你提交 → 立刻出现占位卡片（loading）
      → 后台抓取：标题 / 封面 / 正文 / 截图
      → 自动打标签（配置了 AI 时）
      → 进入搜索索引与向量索引
```

抓取失败不会让收藏消失：卡片会显示状态，并提供重试。

### 2.3 中国内容源

| 站点 | 支持情况 | 如果失败 |
|---|---|---|
| 微信公众号 | 直接取正文（`#js_content`） | 用浏览器扩展「剪藏当前页」，或手动粘贴全文 |
| B 站 | 标题 / UP 主 / 封面 / 简介 | 只存链接与元数据，不下载视频 |
| 知乎 | 问题与回答正文 | 扩展剪藏 |
| 小红书 | 尽力解析 | 风控较强时只能保存链接，请手动补充摘要 |

**原则**：解析失败不算收藏失败。任何站点都能退化成「链接 + 你补充的内容」，仍然可搜索、可被 AI 使用。

## 3. 整理

- **标签**：手动打的标签与 AI 打的标签分色显示；可以在标签页合并重复标签。
- **收藏夹**：支持多级嵌套；可以把收藏夹共享给同事，并设置 `查看 / 编辑` 权限。
- **收藏 / 归档**：星标是「想再看」，归档是「收起来但不占列表」。
- **去重**：同一个链接带不同跟踪参数（`?utm_source=…`）时会被识别为同一条。

## 4. 搜索

搜索框支持三种方式（取决于是否配置了 Meilisearch）：

| 模式 | 说明 |
|---|---|
| 全文 | 标题 / 正文 / OCR 文字 / 高亮 |
| 语义 | 按意思找，「向量数据库」能命中写「embedding store」的文章 |
| 混合 | 两者融合排序（默认推荐） |

**共享给你的收藏夹里的内容现在也能被搜到**（早期版本搜不到，已修复）。

## 5. AI 功能

### 5.1 配置模型

管理员在 `设置 → AI` 里配置：

- OpenAI 兼容接口（可指向自建/中转/Ollama 的 `/v1`）
- 或原生 Ollama

可以分别指定：文本模型、视觉模型、嵌入模型。

> 注意：一旦设置了 `OPENAI_API_KEY`，Ollama 通道会被忽略（上游的优先级设计）。

### 5.2 AI 对话（`/dashboard/chat`）

1. 点「新对话」；
2. 提问，例如「我收藏的关于 RAG 的资料说了什么？」；
3. 回答下方会出现 `[1] [2]` 引用编号，对应你收藏里的具体片段。

**没有依据时它会直接说「你的收藏里没有相关内容」**，不会编造 —— 这是设计如此。

当前限制：回答是整段返回，尚未流式输出；引用编号暂不支持点击跳转（下一步）。

### 5.3 自动标签与摘要

收藏抓取完成后，后台会：抽取正文 → 分块 → 生成标签 → 生成摘要 → 写入向量索引。
这些任务在队列里跑，可以在后台任务页看到状态。

---

## 6. 知识图谱（`/dashboard/graph`）

- 自动从收藏正文里抽取**人物 / 地点 / 组织 / 产品 / 技术 / 概念 / 主题**七类实体；
- 同一句话里出现的实体会连一条边；
- 点节点看详情（出现次数、相关片段）；
- **不需要配置 AI**：抽取先用规则实现，有 AI 时可叠加更准的抽取。

当前限制：节点上限 200，标签密集时可能重叠；大图谱需要换成 canvas 渲染。

---

## 7. 智能专题（`/dashboard/topics`）

输入一个主题（例如「向量数据库选型」）→ 系统从你的收藏里检索相关片段 → 输出一份 Markdown：

- **配置了 AI**：生成带 `[n]` 引用的结构化报告（概述 / 主要观点 / 分歧或空白 / 参考）；
- **没有 AI**：生成「资料概览 + 关键片段 + 待补充」的草稿 —— 明确标注这是草稿，不假装有结论。

报告可以一键复制，粘到你的写作工具里继续加工。

## 8. 支持与打赏

**本产品完全免费，不卖订阅。**

### 接入你自己的模型

AI 功能（自动标签、摘要、对话、专题、创作）需要模型服务。两种接法：

**方式一（推荐）：界面里填**

打开 `设置 → AI`，页面顶部有「模型配置」卡片：

1. 选「OpenAI 兼容」或「本地 Ollama」
2. 填 Base URL 与 API Key（Ollama 只需 Base URL）
3. 填文本模型名（如 `gpt-4o-mini` / `deepseek-chat` / `qwen2.5:7b`）
4. 点「测试连接」验证，再点「保存」

**保存即生效，不需要重启任何进程。**

**方式二：`.env`**

| 方式 | 配置 |
|---|---|
| OpenAI 兼容接口 | `OPENAI_API_KEY` + `OPENAI_BASE_URL` + `INFERENCE_TEXT_MODEL` |
| 本地 Ollama | `OLLAMA_BASE_URL` + `INFERENCE_TEXT_MODEL` |

改完需要重启 web 与 workers。界面配置优先级高于 `.env`。

**没有 Key 也能用**：收藏、搜索、图谱、专题草稿、创作骨架都正常，只是 AI 不会真的思考。

## 9. 常见问题

**Q：收藏一直显示「加载中」？**
后台 worker 没跑，或抓取被目标站点拦截。检查 `workers` 进程与目标站点可达性。

**Q：图片没有封面？**
微信/小红书有防盗链，需要抓取时带 Referer（本项目已自动补），以及必要时配置 Cookie。

**Q：搜索没有结果？**
没配置 Meilisearch 时搜索不可用；配置后需要在管理后台触发一次索引重建。

**Q：AI 功能报「未配置」？**
到 `设置 → AI` 配置模型与 Key。没有 Key 时，标签/摘要/对话/专题的 AI 路径都不可用，
但收藏、搜索、图谱、专题草稿仍然可用。

**Q：数据存在哪？怎么备份？**
全部在 `DATA_DIR` 下（`db.db` + 资产目录）。备份方式见 [DEPLOYMENT](DEPLOYMENT.md) §6 ——
**只拷 `db.db` 会丢最近的写入**，WAL 模式下要连 `-wal`/`-shm` 一起拷，或用 `VACUUM INTO`。

**Q：能离线用吗？**
收藏的正文与资产在本地，但当前 Web 端未做 service worker 离线缓存；PWA 可安装，离线能力待做。
