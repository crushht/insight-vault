## 7. 一期必须砍掉/延后的诱人项

| 项 | 原因 | 处理 |
|---|---|---|
| 视频转码与转录 | 上游无 ffmpeg，引入成本高、存储成本高 | 延后到 Phase 9，先只存元数据 |
| 原生桌面端（Tauri） | 维护两套壳 | 先 PWA，见 ADR-006 |
| 社交/公开主页 | 与私人知识库定位冲突 | 不做 |
| 34 语言全量维护 | 翻译已漂移（el 81KB vs zh 50KB） | 收敛 en+zh |
| 自研支付网关 | 风险与合规成本 | 先接 Stripe/支付宝标准通道，见 ADR-008 |
