**目标**：收藏能力对齐需求，并让中文互联网内容真正可用。

| P3-7 | 知乎适配器 | 问题/回答正文 |
| P3-8 | 抓取失败降级 UI | 「用扩展剪藏 / 手动补充」入口 |
| P3-9 | 文字笔记：阅读台 Markdown 渲染 ✅；编辑态预览待做 |
| P3-10 | 去重 | URL 归一化（utm/锚点/短链）+ 重复提示 |
| P3-11 | 导入 11 种 ✅；**导出 JSON/Markdown ✅**（API + 设置页入口） |
| P3-12 | 导出 | JSON + 资产，可还原 |

| P3-14 | 中文 OCR 验证 | 样本 20 张，准确率 ≥85% |

### 验收

- 四类中国站点各 10 条样本，自动成功率 ≥50%，失败 100% 有降级路径；
- 导入 1000 条 Raindrop 数据无丢失；
- 双进程并发写 1000 次 0 失败；
- 重复收藏识别准确率 ≥95%。
